# Cybersecurity Labs 🔐

## Overview

A collection of hands-on cybersecurity labs completed as part of my Penetration Testing & Ethical Hacking coursework (CYS405) at Prince Sultan University.

These labs focus on network reconnaissance, service enumeration, vulnerability scanning, and security analysis in authorized virtual environments.

## Technical Skills

- Network Discovery & Port Scanning

- Service & Version Detection

- Network Enumeration

- Vulnerability Assessment

- Security Findings Documentation

## Tools & Technologies

- Kali Linux

- Nmap 

- Nmap Scripting Engine (NSE)

- NBTScan

- Nikto

- OpenVAS / Greenbone

- TryHackMe

## Labs

### [01 – Network Scanning](01-Network-Scanning)

**Tools:** Nmap

Explored network discovery, port scanning, and service identification in a controlled lab environment.

### [02 – Network Enumeration](02-Network-Enumeration)

**Tools:** Nmap NSE, NBTScan

Practiced network enumeration techniques involving HTTP, SMB, NetBIOS, and FTP services.

### [03 – Vulnerability Scanning](03-Vulnerability-Scanning-and-Assessment)

**Tools:** Nmap, Nikto, OpenVAS

Lab exercises covering vulnerability scanning, web server configuration checks, and security report interpretation.

## Learning Outcomes

- Developed practical familiarity with network scanning tools.

- Practiced identifying exposed services and potential security weaknesses.

- Learned to interpret vulnerability scan findings.

- Strengthened technical documentation and security analysis skills.

## Disclaimer

All activities are conducted in authorized educational environments for learning and defensive security purposes.
